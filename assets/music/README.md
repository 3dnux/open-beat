# Música local

Coloca aquí tus archivos de audio (`.mp3`, `.wav`, `.ogg`, `.m4a`, `.aac`, `.flac`, `.opus`, `.webm`).
Puedes organizarlos en subcarpetas si quieres.

Al ejecutar `npm start` o `npm run build` se genera automáticamente `manifest.json`
con la lista de canciones, y la app la carga como playlist local.

Si agregas canciones con el servidor ya corriendo, ejecuta:

```bash
npm run music:scan
```

y recarga la página.
